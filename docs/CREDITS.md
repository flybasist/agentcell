# Сторонние компоненты

agentcell не содержит чужого кода: репозиторий состоит из скриптов запуска, Dockerfile и
документации под лицензией GPLv3. Всё перечисленное ниже скачивается на вашем компьютере
при сборке образа и в репозиторий не входит.

## Claude Code

- **Что это:** программное обеспечение Anthropic, устанавливается пакетом
  `@anthropic-ai/claude-code` из npm.
- **Условия:** определяются Anthropic (условия использования и коммерческие условия),
  это не свободная лицензия.
- **Отношение к проекту:** agentcell не распространяет Claude Code и не связан с Anthropic;
  это неофициальная оболочка для его запуска.

## Образ Node.js

- **Что это:** официальный образ `node` из Docker Hub, основа для нашего образа.
- **Условия:** Node.js распространяется по лицензии MIT. Образ собран на Debian и содержит
  пакеты под собственными лицензиями.

## Docker и Colima

Нужны для запуска, но не входят в репозиторий и не поставляются с ним. Их условия
определяются их авторами.
