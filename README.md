# agentcell

Запуск [Claude Code](https://claude.com/claude-code) в Docker-контейнере так, чтобы агент
видел только одну папку — ту, из которой вы его запустили.

> Неофициальный проект, не связан с Anthropic.

## Как это работает

Из вашей системы контейнер видит ровно две папки:

| В контейнере | На вашем компьютере | Зачем |
|---|---|---|
| `/workspace` | папка, из которой запущен `agentcell` | проект, с которым работает агент |
| `/home/agent` | `~/.config/agentcell/state` | хранилище: вход в аккаунт, настройки, кэш |

Домашняя папка, SSH-ключи, другие проекты и сокет Docker контейнеру недоступны.
Контейнер работает не от root, без привилегий и удаляется после выхода.

На macOS у agentcell своя виртуальная машина Colima: в неё смонтированы только папки
проектов, которые вы перечислили в конфиге, и хранилище. Домашней папки там нет, поэтому
при побеге из контейнера ключи и доступы из неё (`~/.ssh`, `~/.kube`, `~/.aws`) остаются
недоступными.

## Что нужно

- macOS 13+ (Colima и Docker CLI) или Linux с Docker (рассчитано на Debian 13).
  **Linux в версии v0.2.0 не проверялся:** проверка запланирована, до неё работа на Linux
  не гарантируется. Основная платформа — macOS.
- Аккаунт Claude с подпиской Pro/Max или API-ключ из Anthropic Console.

## Установка и запуск

```bash
./scripts/install.sh      # macOS: первый раз создаёт конфиг — впишите PROJECT_DIR и запустите снова
cd ~/путь/к/проекту
agentcell                 # интерактивная сессия Claude Code
```

Повторный запуск `./scripts/install.sh` обновляет Claude Code.

**Если у вас уже стоит v0.1.0 (macOS):** `git pull`, затем `./scripts/install.sh`. Он
создаст конфиг и остановится: впишите в него `PROJECT_DIR` (папки с проектами) и запустите
установку снова. Вход в аккаунт сохранится. Подробно: [docs/QUICKSTART.md](docs/QUICKSTART.md),
раздел 8.

Другие режимы:

```bash
agentcell -p "прогони тесты и исправь падающие"   # одна задача без диалога
agentcell --shell                                 # bash внутри контейнера
```

## Плагины

Необязательные возможности подключаются плагинами при установке. Сейчас плагин один: kind
(доступ агента к локальному kind-кластеру, macOS):

```bash
./scripts/install.sh --with kind
```

Правила и подробности: [docs/PLUGINS.md](docs/PLUGINS.md).
